# JS Drill: Arrays

A JavaScript project implementing common array methods from scratch without using their built-in equivalents.

## Methods Implemented

- `each()` – Iterates over array elements.
- `map()` – Creates a new array using a callback.
- `reduce()` – Combines elements into a single value.
- `find()` – Returns the first matching element.
- `filter()` – Returns elements that match a condition.
- `flatten()` – Flattens nested arrays using recursion.
